# Leomenu — Agent Skills

This directory contains specialized skills for the Leomenu AI agent system.

## Structure

Each skill lives in its own subdirectory:

```
agents/
└── skills/
    ├── README.md          ← this file
    ├── <skill-name>/
    │   ├── SKILL.md       ← instructions & metadata (required)
    │   ├── scripts/       ← helper scripts (optional)
    │   └── resources/     ← assets & templates (optional)
    └── ...
```

## Installing a skill

```bash
npx skill install <skill-name>
```
